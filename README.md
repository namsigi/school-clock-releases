# 학교 시계 배포

학교 시간표를 기준으로 현재 교시와 남은 시간을 표시하는 Windows용 시계입니다.

## 다운로드

최신 버전: SchoolClock-v0.9.3-win-x64.exe

- Windows 64비트용 단일 실행 파일
- 별도의 설치 및 .NET 설치 불필요
- 현재 버전: v0.9.3
- 설정 창에서 설정 완료 버튼까지 한 화면에 표시
- 4교시와 5교시 사이를 점심시간으로 표시
- 설정에서 Windows 시작 시 자동 실행 가능
- 수업 시작·종료 전후 1분 동안 마이크로 종소리를 감지해 학교 시각을 한 번 자동 보정

자동 실행을 설정한 뒤 파일 위치를 옮기면 새 위치에서 옵션을 다시 저장하세요.
종소리 자동 맞추기에는 Windows 마이크 접근 권한이 필요합니다.

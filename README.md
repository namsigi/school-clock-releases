# 학교 시계 배포

최신 버전: v0.9.3

## 다운로드 선택

- SchoolClock-v0.9.3-win-x64.exe: 런타임 포함, 바로 실행, 약 134MB
- SchoolClock-v0.9.3-win-x64-small.exe: .NET 10 Desktop Runtime(x64) 필요, 약 1.26MB

Small 버전에서 런타임이 없으면 Microsoft 설치 안내가 먼저 표시됩니다. 앱 설정의 'Small 버전 런타임 설치 안내' 버튼에서도 설치 방법과 공식 다운로드 페이지를 열 수 있습니다.

공식 런타임: https://dotnet.microsoft.com/ko-kr/download/dotnet/10.0
